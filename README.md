# Figure 14: Bibliometric Analysis & Reproducibility Package

# Methodology Documentation
This repository hosts the data and analysis scripts evaluating the relationship between demographic reporting quality and citation desnity metrics within the sampled literature.

# 1. Variables 
- **Independent Variable:** Total Reporting Score (Categorical integer scale 1-3, measuring explicit indexing of Sex, Age, and Race parameters).
- **Dependent Variables:**  Standardized Citation Density (Citations per Year Since Publication).

# 2. Analysis and Design
Statistical plotting and data cleaning were performed utilizing the R programming language. Structural layout configurations adhere strictly to academic design constraints:
- **Typography:** Limited entirely to the **Calibri** font family.
- **Color Palette:** Visual markers are coded exclusively across specified **shades of blue** to optimize contrast and professional aesthetics.

# 3. Instructions for Reproducing
To replicate these graphics:
1. Download or copy this repository to your local workspace.
2. Ensure you have the `ggplot2` packages installed in your R environment.
3. Set your working directory to this folder, open the R script, and run the complete sequence.
